This project is to apply a system that can do both detection and classification on the objects in a video in real time. You Only Look Once (YOLO) detection system is used for generating bounding boxes on the objects and to be able to put labels on them.
YOLO V2 416x416 model and its pre-trained weight is used. Since YOLO DarkNet is natively written in C language, Python deep learning framework called DarkFlow is used as an alternative. The video is processing on a Nvidia MX 940 Graphic Card and getting 11 frames per second (fps).
