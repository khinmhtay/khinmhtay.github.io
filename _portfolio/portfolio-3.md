This project focused on optimizing the cure times for three types Monocure 3D Rapid Photopolymer Resins (Blue, White, Grey, and Clear) used in Stereolithography (SLA) 3D printing to minimize repeated print attempts and achieve optimal model formation. The workflow involved slicing designs via Creation Workshop X, wirelessly controlling the printer using NanoDLP via a Raspberry Pi 3, and configuring precise resin profile parameters such as burn-in and normal layer cure times. Post-processing steps—including cleaning with Isopropyl Alcohol in an ultrasonic cleaner and final UV lamp curing—were established to ensure high print quality across various test components like biosensor packaging, microfluidic devices, and prototype models.
