Developed a system to detect lung cancer from chest x ray images.
Random sample of chest x ray dataset form National Institute of Health is used for training, validation and testing the algorithm.
As a main algorithm, convolutional neural network (CNN) is used to be able to extract and classify lung nodules from chest x ray images.Lung nodule region is located using Class Activation Mappings (CAM). CNN is coded in Python Keras with TensorFlow backend and is trained on Nvidia GPU. The trained and tested CNN model is deployed for easier accessibility.
